## القرارات المعتمدة

وافق صاحب المشروع على المخطط، وفوّض اعتماد المقترحات. القرارات التالية **معتمدة** وتُطبَّق في الكود، وأي تغيير لاحق عليها يُسجل هنا مع تاريخه.

| رمز | السؤال | القرار المعتمد |
|---|---|---|
| **D-01** | أساس الرقابة: الاعتماد السنوي أم التفويض؟ | **مستويان**: الاعتماد سقف للتفويضات، والتفويض سقف للصرف. السنة 2023 على التفويض فقط |
| **D-02** | 9 بنود أرصدتها سالبة في Excel | استيرادها كما هي مع وسم «استثناء تاريخي»، وإظهارها في تقرير التجاوزات |
| **D-03** | المناقلات غير المتوازنة (130 إلى 2/16، و104 إلى 2/17) | مناقلة مستقلة لكل صف «نقل منه»، فيصبح وارد 2/16 = 80,130 ووارد 2/17 = 104 |
| **D-04** | لا توجد تواريخ | إدخالها في شاشة المعاينة، وما يبقى فارغًا يأخذ 31/12/2023 موسومًا «تقديري» |
| **D-05** | معنى `1--12` و`1//12` في الملاحظات | ملاحظة نصية ما لم تؤكد أنها تاريخ |
| **D-06** | تفويض «31/12/2020» في سجل 2023 | معاملته كـ 2023 مع وسم |
| **D-07** | الدفع لحساب الودائع والأمانات أو صندوق التكافل | مصروف فعلي بطريقة دفع «حساب أمانات» |
| **D-08** | الارتباطات غير المسددة في نهاية السنة | ترحيلها إلى البند 2/28 في السنة الجديدة |
| **D-09** | جهة واحدة أم عدة جهات؟ | النموذج يدعم عدة جهات، والتشغيل يبدأ بجهة واحدة |
| **D-10** | من يمنح صلاحية الترحيل رغم العجز؟ | المعتمد النهائي، بسقف ومدة وسبب ومستند |
| **D-11** | دقة المبالغ | 3 خانات عشرية (الدينار = 1000 درهم) |
| **D-12** | هل تُخصم طلبات الشراء (الحجز المبدئي) من المتاح؟ | نعم، مع إمكانية تعطيلها لكل سنة |
| **D-13** | تعريف «نسبة التنفيذ» الرسمية | الفعلي ÷ الاعتماد، مع عرض نسبة الاستخدام (فعلي + ارتباط) بجانبها |
| **D-14** | إرسال بيانات مجمّعة إلى خدمة ذكاء اصطناعي سحابية | يُسمح ببيانات مجمّعة فقط مع إخفاء أسماء الأفراد، ويمكن التعطيل كليًا |
| **D-15** | ترتيب المراحل | تقديم محرك الرقابة والموافقات وبنية التدقيق إلى المراحل 4 و5 و1 |

**افتراض عامل:** قيمة التفويض المالي رقم 479 = **300,000 د.ل** (محسوبة من مجموع توزيعاته). يمكن تعديلها في شاشة معاينة الاستيراد إذا ظهرت قيمة مختلفة في كتاب التفويض.

## التقنيات المعتمدة

| الطبقة | التقنية |
|---|---|
| قاعدة البيانات | PostgreSQL 16 (UUID، وQueries مُعدة، وTriggers، وسلسلة Hash للتدقيق) |
| Backend | Python 3.11+، وFastAPI، وSQLAlchemy 2.0، وAlembic، وPydantic v2، وCelery + Redis، وWeasyPrint، وopenpyxl |
| Frontend | React 18، وTypeScript، وVite، وTailwind CSS (RTL)، وTanStack Query/Table، وRecharts، وreact-hook-form + Zod، وdecimal.js |
| الأمن | Argon2id، وJWT + Refresh مع تدوير، وRBAC + نطاقات، وRate limiting |
| الذكاء الاصطناعي | Claude API (Tool use) بأدوات قراءة فقط، وقابل للتعطيل |
| النشر | Docker Compose على خادم محلي، وnginx، ونسخ احتياطي مشفر |
