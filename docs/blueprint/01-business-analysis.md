# A — تحليل الأعمال (Business Analysis)

## 1. الوضع الحالي (As-Is)

تتابع المراقبة المالية تنفيذ الباب الثاني (النفقات التسييرية) بملف Excel يحاكي النموذج الورقي 23/6. لكل بند ورقة، وتُسجل فيها التفويضات والمناقلات والمصروفات كصفوف متتالية، وتُحسب الأرصدة بمعادلات تراكمية.

### نقاط الألم المُثبتة من الملف (راجع [00-excel-analysis](00-excel-analysis.md))

| المشكلة | الدليل من الملف | الأثر على الرقابة |
|---|---|---|
| الإجماليات غير موثوقة | فرق 63,300 د.ل بين الملخص والحركات | قرارات مبنية على أرقام خاطئة |
| المعادلات قابلة للكسر | استبدال معادلات يدويًا بصفر في 2/16 و2/18 | إخفاء تجاوزات بقيمة 43,500 |
| لا توجد رقابة مسبقة | 9 بنود برصيد سالب، منها 2/25 صُرف منه بلا أي تفويض | الصرف يتم قبل التحقق من الاعتماد |
| المناقلة رقم سالب يدوي | عدم توازن بقيمة 234 | لا ضمان لحفظ القيمة بين البنود |
| لا تواريخ | عمود التاريخ فارغ بالكامل | لا تقارير زمنية ولا تدقيق زمني |
| لا ارتباطات | عمود الارتباطات صفر دائمًا | الرصيد المعروض لا يعكس الالتزامات القائمة |
| لا سجل تدقيق | لا يُعرف من عدّل ماذا ومتى | لا مساءلة |
| لا مرفقات | المستندات منفصلة عن السجل | صعوبة المراجعة |
| لا دورة موافقات | الإدخال = الاعتماد | لا فصل للمهام (Segregation of Duties) |

## 2. الوضع المستهدف (To-Be)

نظام **رقابة على الميزانية (Budgetary Control)** يقوم على **دفتر حركات غير قابل للتعديل (Immutable Budget Ledger)**:

```
مستند مالي (تفويض/مناقلة/ارتباط/مصروف)
   → دورة موافقات
   → فحص توفر الاعتماد (Budget Availability Check)
   → ترحيل (Posting) = قيود في دفتر الحركات
   → الأرصدة والتقارير تُحسب من القيود فقط
```

## 5. المصطلحات (Glossary) — للمراجعة من المحلل المالي

| المصطلح العربي | English | التعريف المعتمد في النظام |
|---|---|---|
| السنة المالية | Fiscal Year | فترة الميزانية (افتراضيًا من 1/1 إلى 31/12)، وكل حركة تنتمي لسنة واحدة فقط |
| الفترة المالية | Fiscal Period | شهر داخل السنة المالية، بحالة مفتوحة أو مقفلة |
| الباب | Budget Chapter | تصنيف رئيسي (الباب الثاني = النفقات التسييرية) |
| البند | Budget Item | تصنيف فرعي داخل الباب (مثل 2/18 الصيانة) |
| سطر الميزانية | Budget Line | تقاطع **السنة × الجهة × البند**، وهو نقطة الرقابة التي تُحسب عليها الأرصدة |
| الاعتماد الأصلي | Original Budget / Appropriation | المبلغ المقرر للبند في الميزانية المعتمدة |
| التعزيز / التخفيض | Budget Increase / Decrease | تعديل الاعتماد بقرار |
| التفويض | Budget Authorization | إذن صرف (إفراج) بمبلغ لجهة عن فترة، ويصدر من وزارة المالية. **مالي**: عام. **مصلحي**: لفترة أو غرض محدد |
| توزيع التفويض | Allocation | تقسيم مبلغ التفويض على البنود |
| المناقلة | Transfer | نقل مبلغ من بند إلى بند في السنة نفسها بقرار |
| الحجز المبدئي | Pre-Commitment / Reservation | حجز مبدئي للرصيد عند طلب الشراء |
| الارتباط | Commitment / Encumbrance | التزام مالي بأمر شراء أو عقد، لم يُدفع بعد |
| الارتباط القائم | Outstanding Commitment | الارتباط − ما سُدّد منه − ما أُلغي منه |
| المصروف الفعلي | Actual Expenditure | مبلغ صُرف فعلًا (أمر صرف أو شيك) |
| الرصيد الدفتري | Book Balance | التفويض الصافي − المصروف الفعلي (وهو ما يعرضه Excel حاليًا) |
| الرصيد المتاح | Available Balance | التفويض الصافي − الفعلي − الارتباطات القائمة − الحجوزات |
| نسبة التنفيذ | Execution Rate | (الفعلي + الارتباطات القائمة) ÷ التفويض الصافي × 100 |
| الترحيل | Posting | تحويل المستند المعتمد إلى قيود في دفتر الحركات، ولا رجعة فيه إلا بقيد عكسي |
| القيد العكسي | Reversal | قيد يعاكس قيدًا مرحّلًا بالكامل، مع سبب |
| التسوية | Adjustment | قيد تصحيح بمبلغ محدد، بموافقة |
| الإلغاء | Cancellation | إلغاء مستند قبل الترحيل، أو إلغاء الجزء غير المستخدم من ارتباط |
| الإقفال | Closing | إقفال السنة المالية وتصفير الحجوزات |
| الترحيل للسنة التالية | Carry Forward | نقل الارتباطات القائمة إلى السنة الجديدة |

## 6. النطاق

### داخل النطاق (المرحلة الحالية)
نظام Budget Control للباب الثاني بالكامل: التفويضات، والتوزيع، والمناقلات، والحجوزات، والارتباطات، والمصروفات، والتسويات، والموافقات، والتنبيهات، والتقارير، والمرفقات، والاستيراد، والتدقيق، والنسخ الاحتياطي، والمساعد الذكي.

### خارج النطاق حاليًا (مع معمارية جاهزة لإضافته)
الباب الأول والثالث، والإيرادات، والحسابات الختامية الكاملة، والرواتب، والمشتريات والعقود كنظام متكامل، والأصول، والخزينة، والموردون كنظام مستقل، والجهات الحكومية المتعددة كنظام مركزي.

**التصميم:** الباب (Chapter) كيان في قاعدة البيانات، ومحرك الحركات لا يفترض الباب الثاني. إضافة باب جديد تكون **بيانات** (بنوده وإعداداته) وليست كودًا جديدًا.

## 7. الافتراضات

1. العملة الوحيدة: الدينار الليبي بثلاث خانات عشرية (D-11).
2. السنة المالية ميلادية من 1/1 إلى 31/12، وقابلة للتغيير لكل سنة.
3. النظام يعمل على الشبكة المحلية، والوصول للإنترنت غير مضمون، لذا يعمل المساعد الذكي فقط عند توفر الاتصال (راجع [12-ai](12-ai.md)).
4. عدد المستخدمين المتزامنين المتوقع أقل من 100، وحجم الحركات حتى ملايين السطور خلال سنوات.
