# L — استراتيجية استيراد Excel (Import Engine)

## 1. المسار

```mermaid
flowchart LR
    U[1. Upload] --> A[2. Analyze] --> M[3. Map Columns] --> V[4. Validate] --> D[5. Detect Duplicates] --> I[6. Detect Invalid] --> P[7. Preview + Decisions] --> C[8. Import] --> R[9. Import Report + DQ Report]
```

| الخطوة | ما يحدث | ما يُحفظ |
|---|---|---|
| 1. رفع | فحص النوع الحقيقي (xlsx = zip + `[Content_Types].xml`)، والحجم ≤ 20MB، وSHA-256، و**رفض ملف سبق استيراده** بنفس البصمة | `import_batches` (UPLOADED)، والملف كمرفق مقفل |
| 2. تحليل | لكل ورقة: كشف القالب (نموذج 23/6 أو غيره)، واستخراج رأس الورقة (الباب، والبند، والقطاع، والسنة)، وتحديد صف العناوين وبداية البيانات | `import_rows.raw` لكل صف |
| 3. ربط الأعمدة | اقتراح آلي (التاريخ←A، البيان←B، المستند←C، المبلغ←D، الفعلي←E، الارتباط←F، ملاحظات←I). **G وH يُقرآن للمقارنة فقط** | `mapping` |
| 4. تحقق | أنواع البيانات، والبند موجود في الدليل، والسنة، والمبالغ | `import_issues` |
| 5. التكرار | داخل الملف، ومع قاعدة البيانات (رقم مستند + سنة + نوع؛ مورد + مبلغ + تاريخ) | issues |
| 6. قيم غير صالحة | كل قواعد §4 | issues |
| 7. معاينة وقرارات | جدول الحركات المقترحة، وعرض كل مشكلة مع خيارات الحل، وإدخال التواريخ الناقصة، واختيار القرار في كل تعارض (D-02 وD-03 وD-04…) | `decisions` |
| 8. استيراد | **معاملة واحدة**: إنشاء المستندات بحالة POSTED وقيودها عبر محرك الترحيل نفسه (لا تجاوز للمحرك)، و`is_historical_exception` حيث ينطبق، و`legacy_ref` = «اسم الورقة!رقم الصف» | المستندات والقيود |
| 9. التقارير | تقرير الاستيراد (عدد ما أُنشئ من كل نوع)، و**تقرير جودة البيانات**، و**مطابقة: Excel مقابل النظام لكل بند** | PDF/Excel |

**الاعتماد:** الاستيراد نفسه يمر بدورة موافقة (مدخل بيانات يحضّر، ومراقب ميزانية يراجع، ومعتمد نهائي يأمر بالتنفيذ). والتراجع (Rollback) ممكن ما دام لم يُرحَّل على السنة نفسها أي مستند غير مستورد بعده.

## 2. قواعد التصنيف لقالب 23/6

| الشرط على الصف | التصنيف | المستند المُنشأ |
|---|---|---|
| كل القيم أصفار أو فارغة | `EMPTY_TEMPLATE_ROW` | لا شيء |
| البيان يطابق `^تفويض\s+مالي` وC رقم وD > 0 | `AUTHORIZATION_ALLOCATION` | سطر توزيع في التفويض (C، السنة، مالي). التفويضات بنفس الرقم عبر الأوراق تُجمع في **تفويض واحد** |
| `^تفويض\s+مصلحي(?:.*من\s+(\S+)\s+الي\s+(\S+))?` | `AUTHORIZATION_ALLOCATION` (مصلحي) | تفويض مصلحي بفترة من/إلى |
| `^نقل\s+منه\s+(?:ل|الي\s+)بند.*?(\d+\s*/\s*\d+|/\s*\d+)` وD < 0 | `TRANSFER_OUT` | سطر مناقلة من هذا البند إلى البند المستخرج (مع تطبيع `2 /16` و`/17` إلى `2/16` و`2/17`) |
| `^نقل\s+له\s+من` وD > 0 | `TRANSFER_IN_AGGREGATE` | **لا يُنشأ مستند**، ويُستخدم للمطابقة مع مجموع الصادر إلى هذا البند (D-03) |
| D = 0 وE > 0 | `ACTUAL_EXPENDITURE` | مصروف: المستفيد = البيان، والمستند = C، والمبلغ = E |
| F > 0 | `COMMITMENT` | ارتباط (لا يوجد في الملف الحالي) |
| البيان يحتوي «الودائع والأمانات» أو «صندوق» | `ACTUAL_EXPENDITURE` + طريقة دفع `DEPOSIT_ACCOUNT` | وفق D-07 |
| أي شيء آخر | `UNCLASSIFIED` | خطأ يمنع الاستيراد حتى يُصنَّف يدويًا |

**المورد:** البيان يُطبَّع (إزالة «السيد /»، وتوحيد الهمزات والتاء المربوطة والمسافات) ويُطابق مع الموردين بتشابه نصي (trigram ≥ 0.70، وهي عتبة معايرة على الأزواج الحقيقية في الملف: 0.76 إلى 0.81) لاقتراح الدمج، مثل «محلات عيسي شحات وابناءه» و«محلات عيسي شحات واباءه» و«محلات الإتقان» و«محلات الاتفان». **الدمج يحتاج تأكيدًا من المستخدم.**

## 3. ربط الورقة بالبند

من رأس الورقة (الخلية التي تحتوي «البند :») بالتعبير `البند\s*:\s*(\d+)\s*/\s*(\d+)`، **وليس من اسم الورقة** (DQ-17). والسنة من نص القطاع `\((\d{4})`، أو من إعداد الدفعة.

## 5. تقرير جودة البيانات (Data Quality Report)

1. **ملخص:** عدد الأوراق والصفوف والحركات المصنفة وغير المصنفة، وعدد المشاكل حسب الشدة.
2. **مطابقة لكل بند:** التفويض، والوارد، والصادر، والفعلي، والرصيد المعاد حسابه، ورصيد Excel، والفرق، والسبب.
3. **مطابقة الإجمالي:** إجمالي Excel مقابل إجمالي النظام، مع تفكيك الفرق (مثل: 63,300 = 19,800 + 18,500 + 25,000).
4. **قائمة المشاكل:** الرمز، والموقع (ورقة!خلية)، والوصف، والقرار المتخذ، ومن اتخذه.
5. **القرارات المطبقة:** D-02 وD-03 وD-04 وغيرها، كما اختارها المستخدم في المعاينة.

## 6. اختبار الاستيراد على الملف الحقيقي

الملف `الباب الثانى.xlsx` يُضاف كـ **Fixture** في `tests/import/fixtures/`، والاختبار يتحقق من:

- 16 مناقلة صادرة، ووارد 2/16 = 80,130 (وفق D-03 المقترح).
- إجمالي الفعلي = 498,674.420.
- ظهور كل رموز IMP المذكورة أعلاه بالعدد المتوقع.
