# O — معمارية الأمن (Security Architecture)

المرجع: OWASP ASVS 4.0 المستوى 2، وOWASP API Security Top 10.

| المجال | الضبط |
|---|---|
| **كلمات المرور** | Argon2id (m=64MB، t=3، p=4)، وطول ≥ 12، ومنع كلمات المرور الشائعة (قائمة محلية)، وتغيير إلزامي عند أول دخول، ولا انتهاء دوري إجباري (NIST 800-63B) إلا بإعداد |
| **قفل الحساب** | 5 محاولات فاشلة تؤدي لقفل 15 دقيقة يتضاعف، مع تنبيه للمسؤول |
| **JWT** | Access token مدته 15 دقيقة (EdDSA أو RS256، والمفتاح الخاص خارج الكود)، ويحمل `sub`، و`sid`، و`roles_version` |
| **Refresh tokens** | عشوائية 256-bit، ويُخزن SHA-256 فقط. **تدوير عند كل استخدام** مع عائلة (`family_id`): إعادة استخدام رمز قديم تلغي العائلة كلها (كشف السرقة). مدة 8 ساعات مع خمول 30 دقيقة |
| **الجلسات** | قائمة جلسات المستخدم مع إمكانية إنهائها، وإبطال فوري عند تغيير كلمة المرور أو الصلاحيات (`roles_version`) |
| **MFA** | TOTP اختياري، وإلزامي للمسؤول والمعتمد النهائي (مقترح) |
| **التفويض** | RBAC + نطاق السجلات (§06)، ويُفحص في كل endpoint، واختبارات صلاحيات آلية لكل endpoint × كل دور |
| **الحد من المعدل** | Nginx (بحسب IP)، وRedis (بحسب المستخدم): الدخول 5/دقيقة، والـ API العام 300/دقيقة، والتصدير 10/دقيقة، والذكاء الاصطناعي 30/ساعة |
| **التحقق من المدخلات** | Pydantic صارم (`extra='forbid'`، وأطوال، وأنماط)، والمبالغ `Decimal` بحد 15 رقمًا صحيحًا و3 عشرية |
| **SQL Injection** | SQLAlchemy بمعاملات مربوطة فقط، ولا تجميع نصوص SQL. التقرير المخصص يختار من قائمة أعمدة بيضاء، و`ruff`/`bandit` في CI |
| **XSS / CSRF** | React يهرب المخرجات افتراضيًا، وCSP صارم (`default-src 'self'`). Access token في الذاكرة (وليس localStorage)، وRefresh في كوكي `SameSite=Strict` + تحقق Origin |
| **رفع الملفات** | قائمة بيضاء (PDF، PNG، JPG، XLSX، DOCX)، وفحص Magic bytes، والحجم ≤ 20MB، وإعادة تسمية بـ UUID، وتخزين خارج جذر الويب، وتنزيل بـ `Content-Disposition: attachment`، ومسح ClamAV (مقترح)، ورفض ملفات Office التي تحتوي ماكرو (`vnd.ms-excel.sheet.macroEnabled`) |
| **الترويسات** | HSTS، وX-Content-Type-Options، وX-Frame-Options=DENY، وReferrer-Policy، وPermissions-Policy |
| **التشفير** | TLS 1.2+ داخل الشبكة (شهادة من CA داخلي)، والنسخ الاحتياطية مشفرة (AES-256، age/GPG)، وأسرار MFA مشفرة بمفتاح تطبيق، والأسرار في متغيرات بيئة أو Docker secrets |
| **قاعدة البيانات** | أدوار منفصلة (§04-5)، والتطبيق لا يملك DDL، وقاعدة البيانات لا تستمع إلا على الشبكة الداخلية لـ Docker |
| **التسجيل** | سجل تطبيق منظم (JSON) بلا كلمات مرور أو رموز، وrequest_id في كل سطر |
| **الاعتماديات** | `pip-audit` و`npm audit` وتحديث شهري للصور، وSBOM |
| **النسخ الاحتياطي والاستعادة** | راجع §15. الاستعادة تتطلب دور المسؤول + تأكيد مزدوج (إعادة كتابة اسم قاعدة البيانات) + نسخة احتياطية تلقائية قبل الاستعادة |
| **اختبارات أمنية** | §14: اختبارات صلاحيات لكل endpoint، وحقن، ورفع ملفات خبيثة، وإعادة استخدام refresh، وتجاوز مراحل الموافقة، وOWASP ZAP baseline في CI |
