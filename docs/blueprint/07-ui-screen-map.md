# I — خريطة الشاشات وتصميم الواجهة (UI/UX Screen Map)

## 1. مبادئ التصميم

| المبدأ | التطبيق |
|---|---|
| نظام مالي مؤسسي، لا جدول Excel | بطاقات موقف، وجداول بيانات بفلاتر، ونماذج في نوافذ منبثقة (Modal) أو صفحات، و**لا خلايا قابلة للتحرير داخل الجداول** |
| الرقم يُفسَّر دائمًا | كل رصيد يُعرض مع مكوناته (Waterfall) ويمكن فتحه حتى الوصول للقيود |
| العربية أولًا | RTL كامل (`dir="rtl"`)، وخط **IBM Plex Sans Arabic** للواجهة و**Tajawal** للعناوين، والأرقام بخط أحادي العرض (tabular-nums) لمحاذاة المبالغ |
| الحالة واضحة | شارة لون وأيقونة ونص لكل حالة (لا يُعتمد على اللون وحده، WCAG) |
| سطح المكتب أولًا | تخطيط 1440px مع قائمة جانبية ثابتة (يمين)، ومتجاوب حتى 768px (الجهاز اللوحي). على الهاتف: لوحة القيادة والموافقات والبحث فقط |
| الاتساق | Design Tokens (ألوان، مسافات، ظلال)، ومكتبة مكونات واحدة، ووضع فاتح وداكن |

**الألوان الأساسية:** أزرق مؤسسي داكن `#0F3D5E` (الأساس)، وأخضر `#1E7F5C` (متاح وطبيعي)، وكهرماني `#B7791F` (تحذير 80%)، وأحمر `#B42318` (تجاوز)، وخلفية `#F6F7F9`.

## 4. لوحة القيادة (S-01)

**صف المؤشرات (KPI):** إجمالي الاعتماد · إجمالي المصروف · إجمالي الارتباطات · الرصيد المتاح · نسبة التنفيذ · عدد المناقلات · العمليات المعلقة · عدد التجاوزات · التنبيهات المفتوحة · بانتظار اعتمادي.

**الرسوم:**

| الرسم | النوع |
|---|---|
| الاعتماد مقابل الفعلي لكل بند | أعمدة أفقية مزدوجة (أفضل مع أسماء عربية طويلة) |
| الاعتماد مقابل الارتباطات | أعمدة مكدسة (فعلي + ارتباط + متاح = اعتماد) |
| الرصيد المتاح | Treemap بحجم الاعتماد ولون نسبة الاستخدام |
| المصروف الشهري | أعمدة مع خط تراكمي |
| استخدام البنود | Bullet charts مع حدود 80% و95% |
| تحليل المناقلات | Sankey (من البنود إلى البنود) |
| مقارنة السنوات | خطوط، سنة لكل خط |
| أعلى البنود صرفًا | ترتيب أفقي (أعلى 10) |
| بنود منخفضة الرصيد | قائمة مع مقياس |
| بنود متجاوزة | قائمة حمراء مع قيمة التجاوز |

كل عنصر قابل للنقر وينقل إلى الشاشة المفصلة بالفلتر المناسب.

## 7. أنماط التفاعل

- **النماذج:** حفظ كمسودة تلقائيًا، وتحقق فوري (Zod) ومطابق لتحقق الخادم (Pydantic)، و**لوحة جانبية للرصيد الحي** تُظهر أثر المستند قبل حفظه.
- **رسالة العجز:** نافذة بعنوان «لا يوجد اعتماد متاح كافٍ لهذه العملية.»، وجدول صغير (المتاح، المطلوب، العجز)، وأزرار: «تعديل المبلغ»، و«طلب مناقلة»، و«طلب استثناء» (إذا كان مسموحًا).
- **الإشعارات السريعة (Toast):** نجاح وفشل الإجراءات، وأما الأخطاء المالية فتظهر في نوافذ وليس Toast.
- **الجداول:** ترقيم صفحات من الخادم، وترتيب، وفلاتر متقدمة محفوظة، وإظهار وإخفاء الأعمدة، وتصدير ما يظهر.
- **لوحة المفاتيح:** ⌘K / Ctrl+K للبحث، و`N` لمستند جديد في القوائم، و`/` للفلاتر.
- **إمكانية الوصول:** تباين AA، وتركيز مرئي، وتسميات ARIA عربية، ودعم قارئ الشاشة للجداول.
