# نظام مراقبة الاعتمادات والمصروفات الحكومية
**Government Budget Control & Financial Monitoring System — GBCFMS**

نظام رقابة على الميزانية (Budgetary Control) يحل محل سجلات Excel في متابعة الباب الثاني: التفويضات، والتوزيع، والمناقلات، والارتباطات، والمصروفات، والأرصدة، والموافقات، والتدقيق، والتقارير.

## الحالة الحالية
مرحلة **التصميم**: المخطط المهني جاهز للمراجعة، ولم يبدأ التنفيذ بعد.
